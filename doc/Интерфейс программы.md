# Интерфейс программы: обзор панелей

## Главное окно программы

После запуска [[Qucs-S]] вы увидите следующую структуру:

![[qucs_main_window.png]]

- **Главное меню** (верхняя строка) — доступ к файлам, настройкам, справке.
	- File - работа с проектами (новый/открыть/сохранить)
	- Edit - стандартные операции (копировать/вставить/отменить)
	- Positioning - размещение компонентов (вращения, выравнивание)
	- Insert - вставка схемных элементов (проводники, маркеры)
	- Project - файловые операции по проекту (создание, закрытие, создание библиотеки)
	- Tools - вспомогательные компоненты (визарды, калькуляторы)
	- Simulation - запуск и настройка расчётов
	- View - управление отображением рабочей области (масштаб, окно [[octave]])
	- Help - доступ к документации
- **Панель инструментов** (под меню) — быстрые кнопки для создания проектов, сохранения, симуляции.
- **Рабочая область** — центральная часть, где создаются и редактируются:
	- Схемы (`.sch` файлы)
	- Графики результатов (`.dpl` файлы)
	- Текстовый редактор для SPICE-скриптов (очень примитивный, рекомендую использовать [[vscode/VSCode|VSCode]] с плагином `xuanli.spice`)
- **Боковые панели** — компоненты, навигация, свойства.

## Боковая панель (Main Dock)

### Вкладка Projects (Проекты)

![[qucs_projects.png]]

- Отображает древовидную структуру текущего проекта:
    - Схемы (.sch)
    - Графики результатов (.dpl)
    - SPICE-скрипты (.cir)
- Позволяет переключаться между файлами проекта.

### Вкладка Content (Содержимое)

![[Pasted image 20250813125911.png]]

Быстрый навигатор по текущему документу:
- Список всех элементов схемы
- Фильтрация компонентов
- Поиск по схеме

### Вкладка Components (Компоненты)

![[Pasted image 20250812172554.png]]

Содержит все элементы для построения схем:

- **Базовые**: Резисторы ([[el/R|R]]), конденсаторы ([[el/C|C]]), катушки ([[L]]), источники питания.
- **Полупроводники**: Диоды, транзисторы ([[BJT]], [[MOSFET]]), [[el/opamp|операционные усилители]].
- **Виртуальные измерительные приборы**: Вольтметры, амперметры, осциллографы.
- **[[SPICE]]-модели** — дополнительные компоненты для [[ngspice]].
- **Управляемые источники**: AC, DC, сигналы, генераторы, зависимые источники тока/напряжения управляемые током/напряжением

_Совет_: Используйте поиск (строка вверху вкладки) для быстрого доступа к нужному компоненту по имени.

### Вкладка Libraries (Библиотеки)

Доступ к установленным библиотекам компонентов:
- Стандартные библиотеки Qucs-S
- Пользовательские библиотеки
- Управление библиотеками
