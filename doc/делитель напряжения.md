# делитель напряжения

https://en.wikipedia.org/wiki/Voltage_divider

![[voltage_divider.png]]

- Два резистора, подключённые последовательно.
- Выходное напряжение:
	- $U_{out}=\frac{R_2}{R_1+R_2}\times U_{in}$

Расчёт делителя является первым уроком в [видео-введении в Qucs-S](https://youtu.be/d3VsmT2pAOc), как самый простой способ показать работу с [[ngspice]], и элементарный схемотехнический расчёт.

- **открываем проект с базовыми схемами**:
	- Dock > Projects > hello_prj > Open
	- File > New > Save as... > `divider`
- **рисуем схему**
	- на резисторах, набрасывая их из боковой панели слева
- **схему нужно запитать:**
	- источники -> источник напряжения постоянного тока
- **для расчёта обязательно наличие символа земли**
	- главное меню > Вставка > Вставить землю
	- или просто `Ctrl+G`
- для соединения используется инструмент Wire (проводник) Ctrl+W
	- или щелчок на неподключенном пине
- **свойства элемента меняются** 
	- двойным щелчком левой кнопки мыши на элементе (открывается отдельное диалоговое окно)
	- двойным щелчком на номинале (изменение непосредственно на схеме)
- для ввода кратных номиналов после числа должна идти **буква множителя**:
	- $k$ кило
	- $m$ мега
	- после номинала и множителя можно явно указать величину (Ohm,..)

Нажатием на [F8] запускаем расчёт по постоянному току (DC bias), на ключевых точках сразу видим значения напряжения и тока.
