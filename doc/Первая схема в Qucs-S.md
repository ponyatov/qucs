# Первая схема в [[Qucs-S]]

0. Настройка рабочей среды
	- по умолчанию проекты создаются в каталоге `$HOME/QucsWorkspace`
	- если вы хотите хранить свой наработки в отдельном репозитории под конролем системы контроля версий ([[git/git|git]]), нужно
		- создать новый рабочий каталог, и настроить в нём контроль версий
			- `mkdir ~/electronix ; cd ~/electronix ; git init`
			- `git add remote gh git@github.com:yourname/electronix.git`
			- `git checkout --orphan 'whoami'`
			- `git touch README.md ; git add -A ; git commit -am "."`
			- `git push -uv gh 'whoami'`
		- или форкнуть/склонировать существующий репозиторий проектов вашей рабочей группы, или этой книги:
			- https://github.com/ponyatov/qucs > Fork
			- `git clone -o git@github.com:yourname/qucs.git ~/qucs`
			- `cd ~/qucs ; git checkout --orphan 'whoami'`
			- `git add -A ; git commit -am "." ; git push -uv gh 'whoami'`
		- если вы ничего не поняли в этих портянках команд, и просто хотите начать работать: создайте/выберите любой подходящий каталог для проектов
	- File > Application Settings... > Locations
		- Qucs Home: `/home/dponyatov/qucs/lib/qucs`
		- Octave Path: `/usr/bin/octave` (аналог языка [[R/R|R]] & [[Matlab]])
		- [Ok]
1. Создание нового проекта
	- Project > New Project...
		- Project name: `hello`
		- [v] open new project
		- [Create]
		- Будет создан пустой проект:
			![[qucs_new_project.png]]
		- создастся каталог пустого проекта, стоит сразу записать пустую схему, и добавить проект в git-репозиторий

2. Добавление схемы
	- по умолчанию создаётся пустая несохранённая схема
	- File > Save All...
		- File name: hello
		- [Save]
	- для добавления нового листа схемы:
		- File > New
		- File > Save as... > `another` `<Enter>`

## Добавление компонентов

Из панели Dock > Components (Компоненты) перетащите на схему:

1. Источник питания
	- категория `sources` (источники)
	- перетащите dc Voltage Source (источник постоянного напряжения) на свободное место схемы
	- автоматически назначится RefDes `V1` (условный номер элемента на схеме)
	- Установите значение `U=9V` в свойствах (двойной клик по компоненту)
2. Резистор
	- категория `lumped components` (компоненты с сосредоточенными характеристиками)
	- перетащите Resistor (резистор)
	- по схеме компоненты перетаскиваются с нажатой левой кнопкой мыши
	- для поворота кликните на элемент и используйте сочетание Ctrl+R (повороты при перетаскивании в qucs не работают)
3. Земля (общий провод, две штуки -- у источника и у нижнего вывода резистора)
	- категория `sources` (источники)
	- Ground (земля)
	- если компонент не удаётся сразу увидеть, используйте поле поиска по имени (при вводе будут отображаться все компоненты, в имени которых есть такая строка)
	- для ввода нескольких одинаковых элементов:
		- кликните в доке нужный компонент, он должен выделится
		- курсор мыши в области схемы поменяет свою форму на внешний вид элемента
		- перемещая корсор мыши и используя скроллер с зажатым Ctrl на клавиатуре, кликните в тех местах где вам нужно вставить элемент
	- при добавлении элементов в режиме выделения в доке их можно поворачивать правой кнопкой мыши, поэтому этот режим удобнее

Если вы работаете на ноутбуке или маленьком мониторе, возможно вам будет удобно открепить Dock в отдельное окно, нажав на кнопку
![[qucs_free_doc.png]]
и пеместить окно дока в более удобное место (пустое место у схемы, или дальняя от вас сторона монитора)

Если вы случайно закроете док, заново открыть его можно через
View > [v] Dock Window

## Соединение компонентов

- включите режим вставки соединений: Insert > Wire или хоткей Ctrl+W
	- вставку провода можно начать щелчком по неподключенному выводу компонента
	- для этого должна быть включена опция File > Application Settings.. > Settings > [v] Start wiring when clicking open node
- в режиме соединений на схеме будет отображаться перекрестье
- кликая начальную и конечную точки, соедините элементы:
	- минус источник + земля
	- нижний вывод резистора + вторая земля
	- верхние выводы между собой
- при движении курсора будет отображаться проводник
	- для добавления промежуточных точек и перегибов кликайте левой кнопкой
	- щелчок правой кнопкой перебирает несколько вариантов ортогонального соединения (углы)
	- прокладка проводника завершается щелчком на выводе компонента или другом проводе, либо двойным щелчком в произвольном месте
	- незавершённую прокладку можно полностью отменить клавишей Esc
- если вы ошиблись, можно откатить редактирование Ctrl+Z

## Добавление измерительных приборов

- категория `probes` (зонды)
	- `Current Probe` (измеритель тока)
	- `Voltage Probe` (измеритель напряжения)
- выделите токовый зонд в доке
	- поместите курсор токового зонда поверх проводника и кликните
	- при вставке двухконтактных элементов поверх проводника выполняется разрыв провода и соединение
	- вытавка компонента в режиме выделения в доке позволяет поворачивать элементы правой кнопкой мыши
- кликните зонд запряжения в доке
	- подключите его параллельно резистору
