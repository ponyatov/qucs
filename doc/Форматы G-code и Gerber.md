# Форматы [[G-Code]] и [[pcb/Gerber|Gerber]]

- [[G-Code]] (Geometric Code)
	- Стандартизированный язык управления станками с ЧПУ ([[ISO/6983]])
	- Содержит команды для управления движением, скоростью и другими параметрами
	- Широко используется в 3D-печати, фрезерных и токарных станках
	- Применение в электронике:
		- Управление CNC-станками для производства печатных плат
		- Сверление отверстий и фрезерование дорожек
		- Гравировка на плате идентификационной информации
- [[pcb/Gerber|Gerber]]
	- стандартный формат для описания печатных плат
	- появился как язык управления фотоплоттером:
		- по рабочему полю в координатах X/Y ездит головка с мощной лампой
		- на стол кладётся лист фотоплёнки, или плата с нанесённым фоторезистом (прямой вывод)
		- после лампы установлен непрозрачный диск-диафрагма с набором отверстий определённой формы и размера
		- лампа светит через диафрагму на плёнку или плату, и формирует пятно которое станет маской или окном в фотошаблоне
	- соответственно в формат команд Gerber входят:
		- команды перемещения по X/Y указанием режима вывода:
			- `X...Y...D01*` рисование с включенной лампой
			- `X...Y...D02*` перемещение с выключенной лампой
			- `X...Y...D03*` отрисовка одиночной апертурной точки вспышкой
		- скорость перемещения и интенсивность засветки определяется настройками плоттера, и не задаётся в `.grb` файле
		- `ADD` команда задания таблицы апертур (для старых плоттеров задаются жёстко для установленного апертурного диска)
			- `C`ircle, `R`ectangluar, `P`olygon
		- команды синтеза произвольных апертур
		- `Dxx*` команда переключения текущей апертуры

## Простая печатная плата 50x100 мм

- `lib/gerber/50x100.grb`

```gerber
G04 50x100mm default PCB*
%MOMM*%
%FSLAX36Y36*%
%TF.Part,Other,example*%
%LPD*%
%ADD10C,0.500000*%
%ADD11C,3.200000*%

G04 Board Edge Layer*
D10*
X0Y0D02*
G01*
X80000000D01*
Y50000000D01*
X00000000D01*
Y00000000D01*
G04 G36*
G04 X80000000Y0*
G04 X50000000Y0*
G04 G37*

G04 Mounting Holes*
D11*
X04000000Y04000000D03*
X76000000Y04000000D03*
X04000000Y46000000D03*
X76000000Y46000000D03*

M02*
```

- рендер с помощью [[pygerber]]
	- `mk/rule.mk`
		```Makefile
		doc/%.png: lib/gerber/%.grb
			bin/pygerber render raster $< -o $@
		```
		```sh
		make doc/50x100.png
		```
