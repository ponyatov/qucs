# Форматы [[G-Code]] и [[pcb/Gerber|Gerber]]

- [[G-Code]] (Geometric Code)
	- Стандартизированный язык управления станками с ЧПУ ([[ISO/6983]])
	- Содержит команды для управления движением, скоростью и другими параметрами
	- Широко используется в 3D-печати, фрезерных и токарных станках
	- Применение в электронике:
		- Управление CNC-станками для производства печатных плат
		- Сверление отверстий и фрезерование дорожек
		- Гравировка на плате идентификационной информации
- [[pcb/Gerber|Gerber]]
	- Официальный стандартный формат для производства печатных плат ([[pcb/Gerber#X2|Gerber X2]] - текущая версия)
	- появился как язык управления фотоплоттером:
		- по рабочему полю в координатах X/Y ездит головка с мощной лампой
		- на стол кладётся лист фотоплёнки, или плата с нанесённым фоторезистом (прямой вывод)
		- после лампы установлен непрозрачный диск-диафрагма с набором отверстий определённой формы и размера
		- лампа светит через диафрагму на плёнку или плату, и формирует пятно которое станет маской или окном в фотошаблоне
	- соответственно в формат команд Gerber входят:
		- команды перемещения по X/Y указанием режима вывода:
			- `X...Y...D01*` рисование с включенной лампой
			- `X...Y...D02*` перемещение с выключенной лампой
			- `X...Y...D03*` отрисовка одиночной апертурной точки вспышкой
		- скорость перемещения и интенсивность засветки определяется настройками плоттера, и не задаётся в `.grb` файле
		- `ADD` команда задания таблицы апертур (для старых плоттеров задаются жёстко для установленного апертурного диска)
			- `C`ircle, `R`ectangluar, `P`olygon
		- команды синтеза произвольных апертур
		- `Dxx*` команда переключения текущей апертуры
		- блоки, описывают группы повторяющихся элементов, могут выводиться со смещением, масштабированием и поворотом (вывод межслоных переходов /via/ и посадочных мест /pad/ из библиотек компонентов)
- [[drill]]
	- файлы сверловки для специализированных координатно-сверлильных станков

На производство описание печатной платы часто отправляется в виде набора gerber-файлов отдельно для каждого слоя:
- `.gbr` или `.ger` - основной формат
- `.gm1` - файл паяльной маски (mask layer)
- `.gto` - файл шелкографии (top output)
- `.gbl`/.`gtl` - нижний/верхний слой медного покрытия (bottom/top layer)

Конкретные расширения файлов определяются тем, каким САПР для разработки плат ([[pcb/EDA|EDA]] CAD) они были подготовлены.

[[pcb/Gerber|Gerber]] более универсальный формат, чем [[G-Code]]: гербер задают геометрию в общем стандартизованном виде, а G-код очень сильно завязан на технологию и конкретный станок, который будет применяться например для гравировки и сверления печатной платы.

В случае, если вместо фотовывода вы планируете использовать механическую фрезеровку, можно использовать пакетную конверсию .grb -> .nc с помощью утилиты [[pcb/visolate|visolate]], которая позволяет отфрезеровать плату в форме диаграммы Вороного только разделяя отдельные контактные поверхности тонкой фрезой заданной ширины.

## Простая печатная плата 50x100 мм

- `lib/gerber/50x100.grb`

```gerber
G04 50x100mm default PCB*
%MOMM*%
%FSLAX36Y36*%
%TF.Part,Other,example*%
%LPD*%
%ADD10C,0.5*%
%ADD11C,7.0X3.2*%

G04 Board Edge Layer*
D10*
X0Y0D02*
G01*
X80000000D01*
Y50000000D01*
X00000000D01*
Y00000000D01*
G04 G36*
G04 X80000000Y0*
G04 X50000000Y0*
G04 G37*

G04 Mounting Holes*
D11*
X04000000Y04000000D03*
X76000000Y04000000D03*
X04000000Y46000000D03*
X76000000Y46000000D03*

M02*
```

- `G04` комментарий
- `MOMM` Measure Output unit MM
- `FSLAX36Y36`
	- `FS` Format Specification
	- `LA` для совместимости с предыдущими версиями формата
	- цифры задают число разрядов до, и после (всегда 6) десятичной точки
	- координаты задаются в виде фиксированного набора цифр без точки, и формат задаёт максимальный диапазон вывода (2=99x99мм), и позицию точки

рендер с помощью [[pygerber]]
- `mk/rule.mk`
	```Makefile
	doc/%.png: lib/gerber/%.grb
		bin/pygerber render raster $< -o $@
	```
	```sh
	make doc/50x100.png
	```
