При моделировании в [[Qucs-S]] важно правильно указывать единицы измерения и множители:
```
V1 1 0 DC 9V      # Источник напряжения 9 вольт
R1 1 2 1k         # Резистор 1 килоом (1000 ом)
C1 2 0 100n       # Конденсатор 100 нанофарад
```
